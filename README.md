Entry for the [make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311): a short text written to intrigue the AI judge reading it.

`main.ts` (Node 22, standard library only) writes the entry — 273 Unicode code points — to `entry.txt` in `$MAKEFUN_OUTPUT_DIR`, or `/output/entry.txt` when the variable is unset. The text is deterministic: every run produces the same file.
